# LuxeGear Landing Page - Design Description

## Overview
A modern, responsive store landing page built with HTML5, CSS3, and Bootstrap 5 (CDN). It showcases a hero banner, featured product cards, an about section, a contact form, and a footer with social links.

## Design Choices
- **Framework:** Bootstrap 5 for responsive grid, components, and utility classes; Bootstrap Icons for iconography.
- **Color Palette:** Dark navbar/footer with a gold accent (#ffc107) for CTAs and highlights to convey premium branding.
- **Typography:** System font stack (Segoe UI) for fast, native, readable text.
- **Layout:** Mobile-first responsive grid (1 col mobile, 2 tablet, 4 desktop) using Bootstrap's col-* classes.
- **Product Cards:** Equal-height cards with fixed image height and object-fit: cover; hover lift + image zoom for interactivity.
- **Hero Section:** Full-width background image with dark overlay for readable white text and a strong CTA.
- **Responsiveness:** Media queries adjust hero height and typography for tablets and mobile; Bootstrap handles most responsive behavior.
- **Accessibility/UX:** Semantic sections with id anchors for in-page navigation; alt text on images; sticky navbar.
